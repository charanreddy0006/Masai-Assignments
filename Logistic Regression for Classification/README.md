# Logistic Regression Fraud Detection

## Overview

This project demonstrates how to build a complete Logistic Regression classification pipeline for detecting fraudulent transactions.

The project uses a small transaction dataset to classify transactions into:

- Legitimate
- Fraudulent

---

## Technologies Used

- Python
- Pandas
- Scikit-learn

---
