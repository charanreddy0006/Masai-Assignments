# Decision Tree Classification - Titanic Survival Prediction

## 📌 Overview

This project demonstrates how to build a complete Decision Tree Classification pipeline using a Titanic passenger dataset.

The workflow includes preprocessing, handling missing values, encoding categorical variables, training a Decision Tree model, evaluating performance, and identifying the most important feature.

---

## 🎯 Objectives

- Load passenger dataset
- Handle missing values
- Encode categorical features
- Split data into training and testing sets
- Train a Decision Tree Classifier
- Evaluate model accuracy
- Analyze feature importance

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn

## 📊 Model Configuration

- Algorithm: Decision Tree Classifier
- Criterion: Gini Index
- Max Depth: 3
- Minimum Samples per Leaf: 1
- Random State: 42
